# 出師表｜古文漫遊

依據提供的《國文（出師表）》PDF（16 頁，教材印刷頁 148–163）製作的互動教學網站。首頁為 `index.html`，無須 npm、編譯或 API 金鑰。適合教師投影與學生自主閱讀。

## 網站內容

- 時代背景、表的文體與 207–227 年互動時間軸。
- 依教材五大段落完整呈現前出師表原文；提供白話翻譯與閱讀線索。
- 10 張字詞卡、三項勸諫、6 題 SWOT 分類、6 題附解析測驗。
- 以劉禪身分寫回信、自動保存、匯出文字學習紀錄。
- 原創 SVG 山水插畫、動畫、Web Audio 互動提示音、系統中文朗讀。
- 全螢幕／音效／裝置／版面／中英介面／字體／色系共七項設定。
- RWD、鍵盤操作、可見焦點、減少動態偏好、PWA 離線快取。

## 本機啟動

在此資料夾開啟終端機，執行：

```sh
python -m http.server 8000
```

開啟 `http://localhost:8000`。直接開啟 index.html 可讀取內容，但 Service Worker 與安裝功能需要 HTTPS 或 localhost，請使用伺服器測試。無第三方 CDN 或外部圖片依賴。

## 上傳 GitHub Pages

1. 在 GitHub 建立儲存庫，例如 `chushi-learning`。
2. 將本資料夾**內的所有檔案與 assets 資料夾**放到儲存庫根目錄；確保包含 `.nojekyll`。
3. 進入 Settings → Pages → Build and deployment。
4. Source 選 Deploy from a branch，分支選 main，資料夾選 / (root)，儲存。
5. 發布完成後開啟 `https://你的帳號.github.io/chushi-learning/`。本專案全部採相對路徑，支援專案子目錄。

若使用 Git：

```sh
git init
git add .
git commit -m "Add interactive Chushi Biao lesson"
git branch -M main
git remote add origin https://github.com/YOUR-NAME/chushi-learning.git
git push -u origin main
```

請將 YOUR-NAME 換成你的帳號。本交付不會代建遠端儲存庫或公開教材。

## 七項顯示與操作設定

| 設定 | 選項與行為 |
| --- | --- |
| 全螢幕 | 開啟／關閉；需瀏覽器支援與使用者操作，Esc 可退出；不保存全螢幕狀態 |
| 音效 | 開啟／關閉；預設關閉；開啟後點擊或作答播放短提示音，朗讀須另按按鈕 |
| 裝置 | 自動／手機／平板／電腦；設定網頁最大寬度與欄數，小螢幕仍保留 RWD 保護 |
| 版面 | 自動／直式／橫式；改變內容欄數，不強制旋轉實體螢幕 |
| 語言 | 繁體中文／英文；導覽、設定、提示、測驗與活動提供英文。古文、中文白話翻譯、字詞訓詁保留中文，供國文教學 |
| 字體 | 縮小 18px／標準 20px／放大 24px；主要課文另放大，採相對單位 |
| 色系 | 跟隨系統／亮色／暗色；跟隨系統時會回應偏好變更 |

## PWA 與離線

初次連線開啟並完成快取後，可離線使用全文、活動與圖片。Chrome／Edge 可透過瀏覽器安裝入口安裝；支援 beforeinstallprompt 時網站另顯示安裝按鈕。iOS Safari 可選分享 → 加入主畫面。是否出現安裝提示由瀏覽器決定。

朗讀依裝置已安裝的中文語音，離線可用性因系統而異。全螢幕也受瀏覽器與裝置限制；失敗時會顯示提示。

修改檔案後，將 sw.js 的 CACHE 版本從 chushi-v1 更新，例如改成 chushi-v2。新 Service Worker 下載完成後，關閉該網站所有分頁再重新開啟，以啟用新版本。不要任意清除其他網站的快取。

## 隱私與學習紀錄

設定、精讀進度、回信保存在 localStorage，無後端、不跨裝置同步。測驗成績只存在當次頁面，重新整理後重設；精讀進度與回信仍保留。清除網站資料會刪除紀錄。私密模式或儲存空間受限時，儲存可能失敗；請使用「匯出學習紀錄」自行備份。匯出為 UTF-8 純文字。

## 教材與素材說明

內容依據使用者提供 PDF。白話譯文、英文導讀、測驗及活動為重新撰寫；全文分段依教材五段，未將「鞠躬盡瘁，死而後已」誤列為本篇原文。SWOT 外部機會與威脅來自教材討論表，應視為課堂分析框架。討論題無唯一答案，網站不以字數或關鍵詞自動評分。

教材延伸頁的人格分類與若干概括敘述未納入核心教學，以課文與可理解的文本分析為主。網站未附原 PDF，也未複製教材畫像或地圖；SVG 插畫與 PWA 圖示為本專案自製。使用與公開發布前，請依你持有教材的授權範圍處理；本專案未替第三方教材另授權。

## 建議驗收

- 手機、平板、桌面寬度均無水平溢出；放大字體後仍可閱讀與操作。
- 七項設定切換後重新整理，除全螢幕外可恢復。
- 時間軸、五段閱讀、字詞卡、SWOT、測驗與回信匯出均可操作。
- 頁面成功快取後，以瀏覽器離線模式重新整理仍可載入。
- 音效關閉時，點擊與作答無提示音；朗讀停止鈕有效。
- 使用 Tab、Enter、Space、Esc 操作，並檢查減少動態與系統暗色偏好。
